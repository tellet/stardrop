# Credits

Every asset shipped with Stardrop, where it came from, and its license.

| Asset | Source | Author | License |
|---|---|---|---|
| Default UI font (Fira Mono subset) | Built into Bevy (`default_font` feature) | The Mozilla Foundation / Telefonica S.A. | SIL Open Font License 1.1 |

| Every sound and all the music | Generated at runtime by `src/synth.rs` | — | Not applicable: nothing is shipped |

All visuals are generated in code as well, so the font above is the only
asset in the game that came from anywhere else.

The code Stardrop is built on is another matter: 393 crates are compiled
into it. They are listed with their licences in `docs/THIRD-PARTY.md`,
regenerated by `./scripts/third-party.sh`.
